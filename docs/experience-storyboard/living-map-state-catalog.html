Design and behavior

  • Direct email, LinkedIn, GitHub and résumé remain visible without opening a form.
  • Form feedback is inline and associated with the relevant field.
  • The proposed close policy retains an unsent draft for the current visit.
  • Pending prevents duplicate submission; failure keeps the message intact.
  • This demo simulates states only. It sends nothing and stores nothing outside this page.

Production success must follow the existing API contract and must not claim delivery without evidence.
